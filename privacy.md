# Privacy policy: pmsub fetcher

Last updated: 12 November 2026

**What it accesses.** With the signed-in user's consent, pmsub fetcher requests read-only access to Gmail (`gmail.readonly`), Google Calendar (`calendar.readonly`) and Google Drive (`drive.readonly`) for that user's own account.

**How the data is used.** The data is saved only on the owner's local computer, where it is indexed for the owner's private use. It is not uploaded to any server.

**Sharing.** The data is not shared with, sold to or transferred to anyone. It is not used for advertising, and it is not used to train AI or machine-learning models.

**Retention and deletion.** The owner keeps the data on their own computer and can delete it at any time.

**Revoking access.** Access can be revoked at any time at <https://myaccount.google.com/permissions>.

**Google API Services User Data Policy.** pmsub fetcher's use of information received from Google APIs adheres to the [Google API Services User Data Policy](https://developers.google.com/terms/api-services-user-data-policy), including the Limited Use requirements.

**Contact.** Through this project's GitHub page: <https://github.com/PavanNVSS/pmsub-fetcher>.
