# pmsub fetcher

pmsub fetcher is a small personal tool. It reads the owner's own Gmail, Google Calendar and Google Drive data with read-only access and saves it only on the owner's own computer, for a private personal-knowledge system.

- It is used only by its owner. It is not offered to anyone else.
- It requests read-only permissions and never changes, sends or deletes anything in Google.
- Data is never uploaded to any server.
